## 概述

在 AI 时代做产品经理的一个讽刺之处在于——我的工作反而比以往更"人"了。

产品管理的工作始终是 **匠艺（craft）与对齐（alignment）的混合体**。在我职业生涯的大部分时间里，我的一周都被后者占据：和跨职能干系人与队友开会、写状态报告、和工程团队梳理 ticket backlog。我习惯了基于直觉做出快速决策，然后陷入漫长的争取、说服和资源协调战中——交付有影响力的产品，常常感觉更像是事务性工作，而非创造性工作。

有了 Claude，我可以压力测试想法、自动化工作流、走出僵局。我终于可以把真正的时间花在和用户、和团队一起打磨那个最重要的部分上：**匠艺**。这些新工作流改变了我的日常，但**最有意义的转变发生在我们开始开发 Claude Managed Agents（目前在 beta）时**——一套用于在云端构建和部署 Agent 的可组合 API。

本文将分享 Managed Agents 如何改变了我作为 PM 的工作方式，以及一些你可以借鉴的模式。

## 产品开发的今昔之变

API 设计过去活在文档和评论线程里；但在 AI 指数曲线上，**我们用我们交付的东西来构建**。一份在文档中读起来漂亮的 spec，第一次拿来真正构建时可能就崩了。借助 Claude Code，我能用预生产版本的 API spec 草拟一个 Agent，**一个下午就能跑通端到端的真实原型。**

我们基于自己用自己原语构建时学到的东西，多次重塑了 API 抽象和 Claude Console 的 UX——这些改动是任何一份持续数周的文档评审都不可能浮现出来的，否则只能等到用户反馈时才会暴露，那就太晚了。我们仍然会争论形态、用 raw curl 请求验证最底层的体验是否令人满意，但 Claude Code 让我从最基本的"hello world"测试到一个可用的 Agent 可以在同一次坐下来时完成。**当我构建这些 Agent 时，我能更具体地预判我们的 harness 和 API 在下一波模型与任务演化中需要怎样灵活调整。**

最初这些原型只是用来塑造产品的，但现在它们也在改变我的日常工作。我作为 PM 的工作流现在清晰地分裂在我们的不同产品上：

- **Claude 和 Claude Cowork** 用于开放性的研究和探索——那种早期、模糊的探索阶段，我希望进行一场持续的对话
- **Claude Code** 一旦我对要解决的工作有了更明确的认识，就用它写一个定制 Agent 并发布出去，构建在 Managed Agents 之上

**双管齐下带来的回报最大。** 一方面，能轻松基于自己的产品构建，提升了我对下一步可以发布什么的想象天花板；另一方面，一旦产品上线，同样的开发肌肉让我能自动化掉那些过去一直停留在 backlog 里的运维长尾工作。

## 产品经理可用的 Managed Agents 用例

现在我会为任何"待完成的工作"启动一个专门的 Agent。构建过程很简单：在 Claude Code 中加载 Managed Agents skill，画一个简单的草图描述我想要什么。开发者也可以使用最新版本的 Claude Code 和内置的 `claude-api skill` 基于 Managed Agents 构建——只要给 Claude prompt：`start onboarding for managed agents in Claude API` 就能开始。skill 调用之后，Claude 会一边构建 Agent，一边解释集成步骤，让我可以随时调整方向。

这些 Agent 的例子包括：

**采用度分析。** 一个对内部数据库有持久访问、并配备了理解我们数据 schema 的 skill 的 Agent，运行查询发现有趣的离群点和模式。借助过往运行的记忆，它能在之前的发现之上不断推进自己的视角。

**开发者情绪监控。** 一个配备了内置 Web 搜索工具和重点领域指引的 Agent，扫描特定域名列表寻找最新的开发者反馈，回报常见话题。由于内容量太大，它会**并行 fan out 给多个 Agent 做研究**，等待结果，再综合发现。

**Demo 构建。** 一个能访问 demo GitHub 仓库、品牌素材和活动 deck 的 Agent，把预制模板转换成针对相关受众（会议、客户会议）量身定做的成熟 demo。

Managed Agents 的 session 在云端运行，所以我可以**走开，回来时工作已经完成**。那些过去因为每次发布都有自己的怪癖而无法规模化的流程，现在用 Managed Agents 都能轻松自动化——每次 Agent 运行都让人感觉充满动能，而不是枯燥乏味。

## 腾出空间打磨匠艺

一年前，所有这类工作都会在跨职能的资源申请、混乱的电子表格、或我从来没机会去尝试的半成品概念中蹒跚前行。现在，有了 Claude 和 Managed Agents，**我可以把自己规模化**，把时间用来和团队一起打磨最有影响力的产品。我现在的一天横跨：和客户一起生成创新想法、和工程同事一起钻研模糊的问题、把真实的创造性精力投入到前沿产品工作中。

如果你是产品经理，并且还没构建过 Agent，那本周就从这里开始。**那些你一直希望存在的实验和工具，离你只有一个 prompt 和几个 API 调用的距离。**
